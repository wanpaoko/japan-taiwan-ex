# Japan & Taiwan Ex 日台旅跑等級

整合 `japan-ex`（日本 47 都道府縣）與 `TaiwanEX`（台灣 22 縣市）的雙地圖「旅跑等級」記錄工具。

## 功能特色
- **同畫面並排雙地圖**：左側台灣 22 縣市（GeoJSON 轉換 SVG）＋ 右側日本 47 都道府縣，同時顯示總等級與分區小計。
- **統一旅跑等級**：
  - `3`：全馬（42.195公里）
  - `2`：半馬（21公里）
  - `1`：休閒跑（10公里以下）
  - `0`：沒跑過
- **多語系切換**：支援繁體中文（`zh`）、日本語（`jp`）、English（`en`）。
- **URL 狀態保存**：69 位數字雜湊 `#<47碼日本><22碼台灣>`，並向下相容舊版 `japan-ex` 的 47 碼連結；可用 `?t=名字` 顯示作者名稱。
- **零建置純靜態網頁**：無需打包或外部 CDN 依賴，可直接匯出單張高解析度 PNG（`japan-taiwan-ex.png`）。

## 本機執行

```bash
cd japan-taiwan-ex
python3 -m http.server 8080
```
